## Purpose
DEX//PULSE is an Andrew-first native macOS reflex layer: resolve explicit context, show a stable object-class directional Veil, execute a bounded Reflex, return an actionable Result Object, record proof through Witness, then RECEDE cleanly to QUIET. Reduce friction without surrendering control.

## Hard constraints
- Apple Silicon macOS 14+ V1. MacBook is primary operator/runtime/CLI target; Big Mac is canonical development/heavy-compute Target.
- Pulse runtime must not require Karabiner, Hammerspoon, Docker, browser extensions, Python, Node, or another helper app.
- Swift/AppKit owns events/windows/Accessibility; Core Animation owns Pulsefront/Veil; Metal owns canonical Strand ribbons; SwiftUI may own persistent management surfaces.
- V1 has **no executable destructive capability**. Core policy rejects destructive risk before executor entry.
- DexDictate wins conflicts. Pulse must not steal its focus, selection, clipboard, trigger state, AX insertion target, or undo assumptions. Opening Pulse never mutates clipboard contents.
- No telemetry, ambient screen recording, hidden payload logging, or silent cloud dependency.

## Lens precedence
Resolve primary context exactly: (1) explicit selected text/file; (2) UI element under pointer; (3) focused Accessibility element; (4) frontmost window/app; (5) existing clipboard read-only fallback. UI controls are V1 objects; without explicit selection, the pointer element is primary. Automatic Lens resolution never synthesizes Cmd-C.

## Interaction
Use `Object -> Reflex -> optional Target -> Result Object`; Results remain actionable. Each recognized object class owns a stable directional layout. Never use one universal verb wheel or AI-reorder learned positions. Pre-freeze layouts may be deliberately tuned; post-freeze changes require an explicit migration/ADR.

Ghost execution stays disabled in V1. Spool and ordinary Results are memory-only unless explicitly pinned; prefer durable references over copied payloads. Witness structured records retain 30 days by default. Habit learning records content-free Pulse interaction aggregates only; default retention 180 days.

## Capabilities
PulseKit owns applicability, Targets, central risk policy, cancellation/deadlines, Result/proof semantics, and availability. DEX//REACH, Ollama, Git/GitHub, DexGate, DexSpeak, DexDiffusion, DexSprite, DexEnhance, DexCast, and future systems integrate as bounded Packs/adapters, not hard-coded core behavior.

Prefer deterministic/native handling first, local model judgment second, explicitly enabled remote/frontier work only when justified. Reflex names describe tasks, not providers. Executor/Target identity must remain visible. Unknown downloaded scripts may be inspected through DexGate but have no V1 execution route.

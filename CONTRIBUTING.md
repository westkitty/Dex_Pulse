# Contributing to DEX//PULSE

Read `PROJECT_BIBLE.md`, `OPERATIONAL_STATE.md`, and the relevant section of `MASTER_IMPLEMENTATION_PLAN.md` before changing implementation.

Rules:

- preserve DexDictate priority;
- do not introduce a V1 destructive route;
- do not add prohibited runtime dependencies;
- keep learned object layouts stable after their freeze gate;
- do not copy GPL QDuo implementation into this repository;
- treat original visual MP4s as immutable fixtures;
- test the actual user path appropriate to the claim;
- update Operational State only from evidence;
- keep personal runtime data/secrets out of Git.

Prefer bounded, test-backed changes over broad rewrites.

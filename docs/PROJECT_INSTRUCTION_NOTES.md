# ChatGPT Project Instruction Notes

`PROJECT_SYSTEM_INSTRUCTION.md` is intentionally compact enough to paste into a ChatGPT Project instruction field without duplicating the repository.

OpenAI's public Projects documentation describes Project instructions but does not publish a stable character limit. DEX//PULSE therefore uses an **internal conservative budget of 5,000 characters**. This is a repository rule, not a claim about OpenAI's current maximum. If the instruction grows, move detail into versioned project docs rather than exceeding the budget.

The Project instruction is a routing/governance layer. Durable project truth belongs in repository files.

Official reference: https://help.openai.com/en/articles/10169521-projects-in-chatgpt

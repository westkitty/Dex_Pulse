# ADR-0010 — Distribution / Sandbox Posture

**Status:** proposed; decide with Phase 0 environment/entitlement proof

DEX//PULSE requires Accessibility, global interaction, local process/Packs, and optional machine/model adapters. V1 planning assumes direct local development/distribution rather than Mac App Store constraints, but this is not yet a locked shipping decision. Do not add App-Sandbox-driven architectural compromises until required capabilities are tested against the actual entitlement/distribution path.

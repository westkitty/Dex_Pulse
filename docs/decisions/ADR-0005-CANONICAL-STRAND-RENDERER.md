# ADR-0005 — Canonical Strand Renderer

**Status:** accepted planning decision

The four owner-supplied MP4 fixtures are highest visual authority. V1 canonical Strands are procedurally rendered ribbon surfaces with twist, transverse barcode segmentation, face/edge/underside distinction, readable crossings, and restrained bloom. Use an on-demand native Metal renderer rather than approximating Strands as glowing stroked curves.
